# Spanish Flashcards

A browser-based flashcard app for practising Spanish vocabulary.

**Live demo:** https://rayjon-moore.github.io/spanish-flashcards

## Features
- Type the Spanish translation and get instant feedback
- Score tracker showing correct answers as you go
- Forgiving answer checking that ignores accents and punctuation
- Skip button for words you don't know
- Review screen at the end listing missed words, with an option to practise just those

## Built with
- HTML
- CSS (custom styles and Tailwind CSS)
- JavaScript (no frameworks)
